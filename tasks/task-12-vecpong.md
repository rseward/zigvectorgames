# Task 12: Implement VecPong

Classic Pong: two paddles, bouncing ball, vector score numbers.

Player 1: W/S. Player 2: Up/Down. Ball bounces off paddles and top/bottom walls.
Score increments when ball passes a paddle. Center dashed line.

Uses vgame for: App, RenderContext (drawRect, drawCircle, drawNumber), audio (bounce.wav).
~100 lines of game code.
